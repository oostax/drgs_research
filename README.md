# Результаты пилота

Локальный интерактивный дашборд за I–III кварталы 2026 года: главная с шестью блоками, подробный анализ и карта ГОСБ. III квартал — срез по 31 августа. Неизвестные значения имеют отдельный статус.

## Запуск

Нужны Node.js 24, pnpm и Python 3.10+. Обработчик данных использует стандартную библиотеку Python; версии JavaScript-зависимостей зафиксированы в pnpm-lock.yaml.

    pnpm install --frozen-lockfile
    pnpm dev --port 4175 --strictPort

Открыть http://127.0.0.1:4175. Готовые агрегаты находятся в public/dashboard; исходные Excel для просмотра не требуются. Приложение не передаёт их во внешние сервисы. Детальные реестры содержат ФИО и клиентские идентификаторы; локальный запуск не является публичным размещением.

## Обновление данных

1. Указать пути к источникам в data/sources.json. На другом компьютере абсолютные пути необходимо заменить.
2. Выполнить подготовку, независимую сверку, тесты и сборку:

    pnpm data:build
    pnpm data:verify
    pnpm test:imports
    pnpm test
    pnpm build

3. Просмотреть output/audit/issues.json, assignments.json, controls.json и independent-checks.json. Неразрешённые назначения и неполные источники сохраняют статус проверки.
4. Просмотреть собранную версию командой: pnpm exec vite preview --port 4176.

Обработчик читает фактические XML-строки каждого листа независимо от объявленного диапазона Excel. Кэш в .cache привязан к SHA-256 файла. Контроль текущего состава — 130 сотрудников и 23 ГОСБ пилота (все отметки M, без фильтра кластера) — намеренно прерывает обработку при изменении состава: новый штат требует проверки и обновления контрольного значения. Непилот — все сотрудники вне этого списка независимо от ГОСБ.

## Устройство проекта

| Путь | Назначение |
|---|---|
| src/dashboard | Три страницы, общие типы, контекст и авторские SVG-диаграммы |
| src/main.tsx | Точка входа React |
| scripts/build_dashboard.py | Чтение Excel, сопоставление, факты, агрегаты, происхождение |
| scripts/verify_dashboard.py | Второй расчёт SQL по каноническим фактам |
| scripts/test_import_rules.py | Проверки идентификаторов и будущих адаптеров |
| data/sources.json | Состав источников и подтверждение полноты будущих кварталов |
| public/dashboard/manifest.json | Справочники и готовые агрегаты |
| scripts/build_supplemental.py | Квартальные обращения/ФОТ, алиасы ГОСБ и восстановление привязок |
| public/dashboard/supplemental.json | Подготовленные новые агрегаты; подключение к UI ещё не завершено |
| public/dashboard/*.json.gz | Реестры пилота, загружаемые при расшифровке |
| public/maps, public/fonts | Локальные геометрии и шрифты |
| output/audit | Машинные отчёты, исходные назначения и реестр проверки |
| .planning | GSD: требования, решения, четыре плана, задачи и результаты |

Новый интерфейс использует только src/dashboard. Прежние исходники сохранены, но не входят в новую точку входа и сборку. Резервные копии предыдущих материалов находятся в output/previous-app.

Контракты будущих источников — в docs/DATA_CONTRACT.md; результат проверки — в docs/VERIFICATION.md; визуальная система — в DESIGN.md. Макет перед реализацией создан в OpenDesign; окончательный работающий результат — приложение React.

Новые источники обращений и ФОТ: после обновления основного manifest выполнить `pnpm data:supplemental` и `pnpm test:supplemental`. Пути находятся в `supplemental` файла data/sources.json. Квартальные правила, сверка кодов 9055/9056 и ограничения получателей описаны в docs/SUPPLEMENTAL_ANALYSIS.md. Исходные числа не исправляются вручную; все восстановленные привязки и отрицательные разности сохраняются в output/audit. Новые агрегаты пока не подключены к карточкам интерфейса.
