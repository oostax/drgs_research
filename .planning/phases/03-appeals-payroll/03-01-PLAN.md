# Обращения и ФОТ

## Границы

Подключить три предоставленные книги, для обращений использовать исключительно лист `d`. Все блоки имеют квартальную ось (уточнение пользователя 03.09.2026). Сохранить стиль остальных блоков, взять графику непосредственно из указанной библиотеки Fikri. Не выдавать месячный срез за полный квартал, ТБ за ГОСБ, пропуски за нули или географию пилота за персональный состав пилота. Исходные книги не изменять. Остальные незавершённые задачи не переписывать.

## Проверка плана

Каждый вид данных сохраняет собственный уровень детализации. Обращения суммируются по кварталам в текущем контексте дашборда; отсутствие года в d больше не блокирует группировку. Ролевой состав обращений в листе отсутствует, фильтр роли не меняет данные ТБ. Для ФОТ Q1=N, Q2=O−N−M, Q3=M (июль, неполный). Получатели: срез марта в Q1, нет данных Q2, срез июля в Q3. Алиасы ГОСБ подтверждены именами отделений, табельными номерами и ФИО; произвольная привязка не нужна. Пропуски и 9 отрицательных разностей Q2 не обнуляются. Нераспределённые клиенты учитываются отдельно. Сопоставление — по каноническому ГОСБ+ИНН с сохранением исходных ключей и сумм.
