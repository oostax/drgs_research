# Контекст

Основание: пользовательский утверждённый план реализации, уточнения штата, требования индивидуального дизайна и ведения GSD. Требования зафиксированы в ../../REQUIREMENTS.md; решения — ../../DECISIONS.md.

GSD выполняется текущим агентом согласно fallback навыка для режима без явно запрошенных подагентов. Исходное приложение сохранено в output/previous-app. Пользовательские исходники Excel не изменяются.

Готовность: локально работающие три страницы и воспроизводимый отчёт проверки. Неустранённые расхождения остаются ограничениями показателей. Получение будущих источников не блокирует завершение этой версии.
