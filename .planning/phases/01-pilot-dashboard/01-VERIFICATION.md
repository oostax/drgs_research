# Проверка фазы

| Требование | Реализация и подтверждение |
|---|---|
| DATA-01 | Новый штат M, роли и отдельная группа непилота; 126 / 22 |
| DATA-02 | Явные соответствия 9500, 9600, 9042; сырые значения и основания |
| DATA-03 | Все фактические XML-строки; SHA-256, размеры листов и исходные суммы |
| CALC-01 | Уникальные ID, все стадии, исключение зарплатного продукта по умолчанию, отдельный знаменатель сложных |
| CALC-02 | Повторы сотрудник–ИНН, нули и отсутствие, DISTINCT-покрытие |
| CALC-03 | Завершённость и дедупликация анкет, шкала 1–3, адаптеры |
| UI-01 | Главная 6 блоков; кварталы, группы, сигналы, свёрнутые фильтры |
| UI-02 | Общий контекст, пять разрезов, поиск и источник |
| UI-03 | Карта, масштаб, выбор, квартал и показатель, общие значения |
| QA-01 | 15 854 расчётные проверки, 24 теста, браузер, сборка и воспроизводимость |

Результат: требования первой версии реализованы. Исторические назначения и полнота отдельных источников остаются ограничениями данных; сравнения с такими основаниями обозначены и не выдаются за достоверные.

Подробные сценарии, значения и границы независимости второй сверки: docs/VERIFICATION.md. Изменение источников требует нового выполнения проверок.
