# Утверждённые изменения

По запросу пользователя: усилить иерархию, увеличить мелкий текст и проценты, убрать бледность и наложения, постоянно показывать фильтры с кастомным селектом по nastroenije. Сохранить спокойную палитру. Сделать сетку компактнее, стадии и данные читаемыми без наведения. Добавить аккуратные анимации графиков, переключений и морфинг SVG без смещения блоков. Расчётные правила и источники остаются прежними.

Решение: Radix для селектов и поискового списка ГОСБ; подписи и числа постоянно видимы; зелёный/графитовый для групп, фиолетовый для сложных продуктов. Состояния полноты выделены полезными бейджами. Подписи стадий, значения и доли показаны непосредственно в блоке.
