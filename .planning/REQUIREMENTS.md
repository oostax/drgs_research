# Требования

- **DATA-01.** Новый штат: все отметки M без ограничения кластерами; роль из M; идентификация по табельному номеру, затем однозначному ФИО. Непилот — все сотрудники вне списка пилота, независимо от ГОСБ, все роли. В текущем файле 130 участников пилота, включая четырёх сотрудников Коми №8617.
- **DATA-02.** Справочник 2026; СПб №9500, ЛО №9600, три подтверждённых назначения №9042. Исходные значения и основания исправлений сохранены.
- **DATA-03.** I–II кварталы из прежних файлов, III из новой выгрузки. Все листы и строки читаются независимо от диапазона Excel. Контрольные суммы сохраняются.
- **CALC-01.** Сделки — уникальные ID предложений в срезе, все стадии, по умолчанию без ФОТ. Сложные продукты: согласованный перечень, старшая роль, знаменатель без ФОТ.
- **CALC-02.** Встречи: устранение повторов по сотруднику и ИНН; конфликтующие значения на проверке. Покрытие: объединение уникальных ИНН II–III кварталов к закреплённой базе. Отсутствие сотрудника не равно нулю.
- **CALC-03.** Анкеты: завершённость, шкала 1–3, последний вариант по ключу ID + создание. Процесс — первые три вопроса; лиды — четвёртый. Отдельные адаптеры ФОТ и обращений.
- **UI-01.** Главная: шесть блоков, три квартала одновременно, две группы, динамика, свёрнутые фильтры, переходы из сигналов. Индивидуальный дизайн с референсом Fikri.
- **UI-02.** Анализ: ГОСБ, продукты, стадии, сотрудники пилота, поиск, исходная строка. Сохранение контекста в URL.
- **UI-03.** Карта: реальные геометрии, масштабирование, квартал, показатель, список и выбранный ГОСБ. Общие агрегаты с другими страницами.
- **QA-01.** Независимые суммы, границы долей и покрытия, неизвестное и нулевая база, неполные периоды, малые выборки, клавиатура, мобильный экран, reduced motion. Воспроизводимая пересборка и отчёт.

Вне первой версии: загрузка файлов через экран; прогноз; доказательство причинного эффекта; подмена ФОТ суммами предложений; публичное развёртывание без поручения.


- **UI-04.** Все основные фильтры видны; кастомные селекты и поиск ГОСБ, клавиатура.
- **UI-05.** Основной текст 14–16px, явные стадии/доли, контраст и отсутствие наложений без наведения.
- **UI-06.** Устойчивая компактная сетка, полезные бейджи, морфинг SVG и reduced motion.
