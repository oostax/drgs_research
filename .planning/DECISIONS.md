# Решения

1. React/Vite сохраняется. TypeScript — интерфейс, Python — Excel и расчёты, SQLite — независимая сверка.
2. M определяет участие и роль пилота без фильтра кластера: 130 участников, 23 ГОСБ. Пользователь 02.09.2026 подтвердил: непилот — все сотрудники вне списка пилота, включая сотрудников пилотных ГОСБ и неизвестные ГОСБ в общем итоге. Июльский список 64 КМ — прежний источник, не замена обновлённому штату. Непилот подписывается «Непилот · все роли».
3. Главная показывает три квартала одновременно. Детализация и карта используют сохранённый контекст URL.
4. Неизвестные значения — null с причиной. Неполные наблюдаемые суммы не выдаются за подтверждённый итог; динамика для них отключена.
5. Реестры загружаются по запросу; сотрудники и исходные записи доступны в части пилота. Непилот агрегирован.
6. Пользователь повторно закрепил Fikri Chart Library и потребовал индивидуальный дизайн уровня «вау», который сразу понятен руководителю. Светлая тема, крупные числа, осмысленные разные графики, аккуратное движение.
7. Макет создан в OpenDesign через новое MCP-подключение. Старый транспорт закрыт. CLI использует другой контекст; запись выполнена через MCP.
8. Фактический ФОТ и обращения ожидают источников; суммы предложений их не заменяют.
9. Пользователь 02.09.2026 подтвердил: отсутствие сотрудника в выгрузке встреч означает 0 встреч. Такие сотрудники не блокируют квартальные итоги, динамику и покрытие по имеющейся закреплённой клиентской базе. Отсутствие пилотного сотрудника не применяется к непилоту. Пустая клиентская база не превращается в 0% покрытия; реальные конфликты идентификации/повторов остаются ошибками данных.
10. Недельный режим размещён прямо в карточке «Количество продаж» через «Кварталы / Недели». Даты — последняя смена стадии, не новые продажи; подпись обязательна, квартальный график и квартальная динамика скрываются. После отклонения варианта с двумя полосами пользователь повторно закрепил образец с нейтральными округлыми столбиками, цветной выбранной неделей и числом над ней: два мини-графика рядом, синхронный выбор, явно подписанные собственные шкалы. Квартальный режим и остальные карточки сохраняются.
